# Sample data (synthetic)

Generated by `python scripts/make_samples.py`. Nothing here is real data.

| file | what | why |
|---|---|---|
| demo_process.csv | 20 groups x 400 rows, header, timestamps, injected faults (step, ramp, stuck sensor, correlation break, oscillation, noise burst) and DQ issues (missing block, spike, frozen block, unit shift, duplicates, timestamp gap); no labels | the default demo (`python -m tpm demo`) |
| demo_process_labeled.csv | 12 groups x 300 rows with a `fault_label` column | shows label auto-detection, exclusion from detection, and the evaluation section |
| demo_headerless.dat | whitespace-separated, no header, numeric only | shows blind-mode ingestion (aliases S01..Snn) |
| demo_records.csv | order-like business records with manual-entry errors (cents-instead-of-euros, price-table drift, missing ids, negative quantities, duplicates, late-entered batch, copy-paste frozen field) | shows the same pipeline on non-sensor data (docs/ADAPTABILITY.md) |
